# Social platform publishing notes

These notes were verified against official provider documentation on 19 August 2026.

| Platform | Verified capability or requirement | Official source |
|---|---|---|
| Facebook Pages | Pages API supports creating Page posts; publishing requires Page access tokens and permissions such as `pages_manage_posts`. | https://developers.facebook.com/documentation/pages-api |
| Instagram Professional | Content Publishing API supports single images, videos/Reels, and carousels; media must be hosted on a publicly accessible server at publishing time; Stories are not supported by the documented API. | https://developers.facebook.com/documentation/instagram-platform/content-publishing |
| Threads | Threads API supports creating and publishing posts; documented text limit is 500 characters, with image/video specifications and publishing limits. | https://developers.facebook.com/documentation/threads/overview |
| YouTube | YouTube Data API supports OAuth 2.0 video uploads with title, description, tags/category metadata, and public/private/unlisted privacy status. | https://developers.google.com/youtube/v3/guides/uploading_a_video |
| X | X API documents media upload for images, GIFs, and videos, followed by attaching media IDs to posts. | https://docs.x.com/x-api/media/introduction |
